# Custom Hyprland modules

Place future standalone, non-Omarchy Lua modules here and load them from
`../config.lua`. The custom profile is currently empty and does not configure
a usable desktop. It must not depend on Omarchy's bootstrap, helpers, or defaults.

Example Directories
- animations.conf
- autostart.conf
- binds.conf
- decoration.conf
- env.conf
- input.conf
- layout.conf
- misc.conf
- monitors.conf
- programs.conf
- windows.conf
