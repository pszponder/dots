# 💤 LazyVim

A configuration based on the [LazyVim starter](https://github.com/LazyVim/starter).

- LazyVim follows stable releases; `lazy-lock.json` records the verified plugin versions.
- The default theme is Catppuccin Mocha with a transparent background.
- Requires Neovim >= 0.11.2 with LuaJIT.

Start with `NVIM_APPNAME=nvim-lazyvim nvim` after installing these dotfiles.
Run `:Lazy update` to update LazyVim and its plugins, then restart Neovim.

Refer to the [documentation](https://www.lazyvim.org/) for configuration and extras.
